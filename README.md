## What i've learned 

`type="email"` validates that the input looks like an email address.<br>
`type="password"` hides the password as it is typed.<br>
`required` prevents the form from being submitted if the field is empty.<br>
`type="checkbox"` creates the Remember Me option.<br>
`type="submit"` creates the Login button.<br>

**Note:** HTML validation improves the user experience by catching empty or invalid input in the browser. <br>
For real-world applications, you should always validate the data again on the server, <br>
since client-side validation can be bypassed.<br>
